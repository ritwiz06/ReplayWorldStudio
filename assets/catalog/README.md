# Equipment asset catalog

This directory is the **catalog library**: the API serves model files from here (`RWS_CATALOG_DIR` overrides the location), and project files refer to them by library-relative path plus sha256. See docs/contracts.md for the path rules, the fit to recorded dimensions, and portability.

Exact bounds and hashes are in `models/manifest.json`. All models are authored in metres, +Y up, front facing +Z, with the origin at the bounding-box bottom-centre, and use one PBR material per surface type (painted steel, aluminium, rubber, polycarbonate, emissive signals and so on). No textures.

## Authorship, source and rights

- **Authorship.** Original procedural models, created for this repository. They are generated by `apps/web/scripts/catalog/` (written with AI assistance in the WRL-02 session, 2026-10-10) from simple solids. They are illustrations of *generic* equipment and do not reproduce any manufacturer's product, drawing or model.
- **Source.** Each catalog entry records `source.kind = in_house`, the author "Replay World Studio project (procedural model generator)" and the generator path as its reference.
- **Rights.** `license: NOASSERTION`, `redistribution: unknown`. The project owner has not chosen a license, and none is assigned on their behalf. Choosing one is an open decision (see prompts/DECISIONS.md).
- **No third-party content.** No downloaded models, textures or fonts are included.

## Rebuilding

```bash
pnpm assets:build    # regenerate the GLB files and manifest.json (deterministic)
pnpm fixtures:build  # copy the new hashes and bounds into fixtures/scenes/industrial-demo.json
pnpm assets:check    # CI: committed models must rebuild byte-for-byte
```

Output depends on the three.js revision (r186 now). Upgrading three.js may change bytes and therefore hashes; rebuild and commit both commands' output together.

## Adding licensed third-party assets later

Record `source.kind` (`vendor` or `third_party`), a `reference` to the original, and the actual SPDX license or `LicenseRef-…`. Large or restricted vendor files belong outside version control in a separate library directory pointed to by `RWS_CATALOG_DIR`.
