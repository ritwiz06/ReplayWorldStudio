# Rubric (one row per sheet)

## score: can you see the requested change in the After picture?

| Score | Meaning |
| --- | --- |
| **2** | Yes: the requested change is clearly visible and looks right. |
| **1** | Partly: something is there, but it is hard to see, incomplete, or partly wrong. |
| **0** | No: it is missing, hidden, or wrong. |

- Only the part of the request that a picture can show counts. For example, "wheels that roll":
  judge whether there are wheels, not whether they roll.
- An orange outline around something you cannot see does not make it visible.
- A change the request did not ask for (another part moved, recoloured, or left floating in
  the air) lowers the score if it makes the result wrong.

## looks_done_but_is_not: yes or no

Answer **yes** if a person glancing at the After picture would probably think the request was
done, but on a closer look it is not. Examples: glass that shows a solid wall behind it where
the request implies seeing inside; parts left floating in the air.

## note (optional)

One short sentence, in your own words. For example: "Door looks clear, but there is a solid grey
block behind it."
